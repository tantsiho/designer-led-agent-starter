## Question Types The Agent Must Ask

- Does this term have a fixed definition?
- When these two rules conflict, which wins?
- What happens when the user is logged out?
- What happens when permissions are insufficient?
- What happens when data does not exist?
- What happens when an external service fails?
- Is this required for MVP, disabled for now, or future work?
- When a feature is disabled, should UI, API, and direct route all reject it?
- What data must not be public?
- What would mislead users about the product?
