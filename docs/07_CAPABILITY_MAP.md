| 能力 | 分類 | 狀態 | 備註 |
|---|---|---|---|
| 待填 | 現在主線 / 關閉中 / 未來工程 / 歷史參考 | not started / partial / complete / blocked | 待填 |

## 假完成檢查

每條能力都要問：

- 是否只有 UI？
- API 是否真的存在？
- 資料是否真的保存？
- 重新整理後是否還在？
- 權限是否正確？
- 錯誤狀態是否可處理？
- 測試是否驗證真流程？
- 是否只在 engineering mode 可用？
- 是否存在未確認的產品、法務、價格、資料、受監管流程或 provider 決策？
- 這條能力是否踩到 `02_PRODUCT_TRUTH.md` 的明確不做事項？
