## 資料漂移檢查

代理要檢查：

- 重新整理後資料是否還在？
- 重啟 server 後資料是否還在？
- 本地資料和遠端資料衝突時誰優先？
- seed/mock 資料是否會混進正式資料？
- 刪除、取消、失效後舊資料是否會復活？
